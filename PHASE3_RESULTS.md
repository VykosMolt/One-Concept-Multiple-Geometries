# PHASE3_RESULTS.md

**TRANSIENT LEXICAL BIAS** in behaviour (dose-dependent: an aligned open-line code accelerates acquisition of the
oracle's own neighbourhood structure and delays equalization of the duplicated labels, all gone by convergence) **+ a
small, persistent OUTPUT-CODE effect on REPRESENTATION only** (a +0.08…+0.10 line tilt of the `<Q>` geometry in 5/5
paired seeds and a dose-dependent open-boundary "bow", while behaviour is Bayes-optimal). At convergence, **predictive
statistics dominate behaviour**: every model reproduces its oracle to KL ≤ 0.001 regardless of the output code, and an
aligned code never pushes a periodic law's behaviour beyond the line component the oracle itself has. The positive
control passes: an arbitrary code does not hide a true line.

*(Design frozen in `PHASE3_DESIGN.md` before any run; chronology in `PHASE3_LOG.md`; code in `synthetic/`; unit tests
in `tests/test_synthetic_phase3.py` (11 checks, all pass); raw per-run trajectories, log-prob matrices, configs and
relabeling nulls in `results/phase3/runs/`; aggregate tables generated by `synthetic/analyze.py` — no hand-edited
numbers; figures in `figures/phase3/`.)*

## 1. Exact factorial design
2 (true law: CIRCLE, LINE) × 2 (output code: LINE_ALIGNED, PERMUTED_CODE) × 5 paired seeds = 20 runs, 6000 steps each
(≈ 40 s on the laptop GPU). Seed k fixes: the model initialization, the training-batch order, the source sequence and
the uniform variates used to sample targets (so CIRCLE/LINE and ALIGNED/PERMUTED datasets differ only through the law
and the code assignment), and the permutation π_k. 15 atomic source tokens `<S_−7>…<S_+7>`, one shared query token
`<Q>`, 8 code symbols from a 3-symbol alphabet; loss on the 8 code positions only. Decoder-only transformer, 4 layers,
d=128, 4 heads, learned positions, AdamW 1e-3 cosine, batch 256, 300k training / 20k validation examples. No music
vocabulary anywhere. The `<Q>` residual (identical token for all sources) is the predictive-state probe.

## 2. Oracle transition matrices (`results/phase3/oracles.npz`)
CIRCLE: P(m|n) = P_z(z(m)|z(n)) / mult(z(m)), P_z(z′|z) ∝ exp[2.0·cos(2π(z′−z)/12)]; class marginal from any source
[0.270, 0.207, 0.099, 0.037, 0.013, 0.007, 0.005, 0.007, 0.013, 0.037, 0.099, 0.207] (a rotation of this for every
source); twin sources (−7,+5), (−6,+6), (−5,+7) have identical rows; twin targets receive exactly equal mass; no
open-line coordinate (unit-tested). LINE: P(m|n) ∝ exp(−|m−n|/τ), τ = 2.2455 solved so that both laws have mean row
entropy 2.1368 nats. Oracle self-geometry (the values a perfect learner must show): CIRCLE circle|line 0.98,
line|circle 0.44 without code control (0.13 with it); LINE circle|line 0.00, line|circle 0.995.

## 3. Code construction (`synthetic/codes.py`)
One fixed set of 15 codewords, length 8, symbols {c0,c1,c2}: codeword_i[p] = ⌊(i+p)/8⌋. Hamming distance between
codewords i and j is exactly min(|i−j|, 8) (unit-tested); Levenshtein identical; prefix overlap ρ = 0.73 with |i−j|.
LINE_ALIGNED assigns codeword n+7 to state n: Spearman(code distance, |n−m|) = 0.99, with circle distance 0.30, twin
pairs at maximal distance 8, adjacent states at distance 1. PERMUTED_CODE(k), k = 0…4: the same 15 codewords permuted;
|Spearman(code distance, |n−m|)| ≤ 0.12, twin distances 3.7–6.3, symbol counts [36, 63, 21] and lengths identical to
the aligned set by construction.

## 4. Convergence
All 20 runs: validation loss at the entropy floor, KL(q‖oracle) ≤ 0.001, Spearman with the oracle ≥ 0.989 (CIRCLE)
/ ≥ 0.997 (LINE). Not a design failure; the tiny models are Bayes-optimal in every cell.

## 7. Training trajectory (`figures/phase3/trajectories_main.png`; table in `analysis_uncontrolled.txt`)
CIRCLE law, aligned − permuted, paired: at steps 50/100/150 the aligned models are much closer to the oracle (KL 0.078
vs 0.276 at step 100) and already at the oracle's own line|circle (0.44/0.38 vs 0.21/0.11; Δ = +0.23…+0.27, 5/5 seeds);
twin-target asymmetry is higher under aligned code from step 100 to ≈ 1500 (+0.06…+0.27; the two maximally-different
codewords of a twin pair are equalized more slowly); both differences are ≈ 0 by step 500–2000. The hidden line|circle
shift (+0.05…+0.12) appears by step 400–500 and persists to the end. So the lexical effect on *behaviour* is a
transient of optimization (faster learning of the smooth neighbourhood structure; slower equalization of twins), never
an overshoot beyond the truth; the effect on *representation* is small and permanent.

## 8. Dose-response (CIRCLE law; achieved alignment ρ ≈ −0.03, +0.23, +0.46, +0.71, +1.00; 3 seeds each; `results/phase3/dose_analysis.txt`, `figures/phase3/dose_response.png`)
Across the 15 runs (Spearman with alignment ρ): behavioural line|circle at step 100 **+0.85** (≈ +0.05 at ρ≈0 → +0.24…+0.37
at ρ≈.5 → +0.37…+0.42 at ρ=1; the oracle's own value is 0.44), KL at step 100 **−0.68** (0.28 → 0.06–0.09), PC2-quadratic
bow at the mid layer **+0.57** (0.28–0.60 → 0.69–0.87), twin-target asymmetry at step 500 +0.23, hidden line|circle
shift +0.29 (mid) / −0.09 (last), final KL none (0.0006–0.0008 everywhere). So the two effects that are dose-dependent
are the transient acceleration toward the oracle's line-like neighbourhood structure and the open-boundary bow in the
predictive-state geometry; the small line|circle partial shift found in the binary contrast does not scale cleanly with
alignment and should be regarded as marginal.

## 8b. Follow-up: rare alternative spellings (CIRCLE law with 0.9/0.1 twin split; 3 paired seeds; `rare_analysis.txt`)
Oracle twin-target log-ratio 2.197. Excess asymmetry (model − oracle): aligned +0.43 / permuted +0.14 at step 100,
seed-dependent and noisy through step 2000 (one seed +1.7 under the aligned code at step 500), −0.03 / −0.005 at step
6000; KL 0.0006 both. The hidden line|circle shift (+0.06…+0.09, 3/3 seeds from step 2000) is present as in the main
factorial. With 300k examples the rare-twin transient is not frozen in; a genuinely data-sparse regime (orders of
magnitude fewer twin observations) was not run (stop condition).

## 9. Aligned-vs-permuted effect across seeds — summary
Representation: 5/5 seeds, +0.08…+0.10 (line|circle at `<Q>`), plus the PC2 bow (0.85 vs 0.39). Behaviour at
convergence: none (KL, circle|line, twin-source JS identical; twin-target asymmetry +0.013). Behaviour in training: 5/5
seeds at steps 50–150 (Δ line|circle +0.23…+0.27 toward the oracle value), twin asymmetry +0.1…+0.27 through step 1500.
Positive control (LINE × PERMUTED): behaviour line 0.995 = oracle, hidden line|circle +0.46 with an arbitrary code.

## 10. Strongest counter-evidence / limitations
- The representational effect is ≈ 0.1 on a partial-correlation scale and below the per-run relabeling null; it is
  established only by pairing (5/5) — a real but small effect.
- The "transient line" in behaviour is not an excess over the truth: the CIRCLE oracle already has line|circle 0.44
  over 15 labels (because the three duplicated labels give the observed space a line-like margin). The aligned code
  simply reaches that value faster. A cleaner measure of lexical bias is the twin-target asymmetry, and there the
  effect is +0.1…+0.27 log-units mid-training, +0.013 at the end.
- One codeword family (a thermometer-like window code), one alphabet, one model size; the effect size may depend on
  code length and on how much tokens are shared between neighbouring codewords.
- Single-step transition task; natural next-key prediction embeds the relation in long contexts.
- Partials on 105 pairs remain low-powered; the PCA statistics (PC2 quadratic 0.85 vs 0.39) are the more legible
  representational signature.

## 11. What this says about the natural Phase-II result
This experiment establishes **sufficiency of a weak effect and insufficiency of a strong one**: an open-line output
code, holding the statistics perfectly periodic, can (a) tilt predictive-state geometry toward the line by ≈ 0.1 and
imprint an open-boundary bow, and (b) delay the equalization of enharmonic-like twins during learning — but it
**cannot** make converged behaviour line-like when the statistic is periodic. The natural models show a strong
behavioural line (line|circle +0.3…+0.6, twin asymmetry large, enharmonic twins far apart) at the end of training.
Therefore the easiest lexical-output explanation of the natural line — "spelled outputs alone induce the line over a
periodic statistic" — is **not sufficient**. Either the natural predictive statistic is itself line-like in a way our
symmetric and cue-conditioned Wikipedia statistics did not capture (e.g., long-range or document-level conditioning),
or the models never received enough evidence to equalize enharmonic twins (the twin-asymmetry transient never
finished: rare spellings, few equivalence statements), or the line is genuine tonal-spelling knowledge. The synthetic
result favours the second reading — a *very slow* transient in a data-sparse regime — as the most economical, and it is
directly testable: twin-target asymmetry in the natural models should fall with the corpus frequency of explicit
enharmonic equivalence, and the 7B model (which knows the equivalence) should show the smallest asymmetry — it does.
This is a hypothesis, not a demonstrated mechanism.

## 12. Technical note or paper?
Still a technical note, but a more coherent one: (Phase I) corpus periodic, LLM key-name geometry orthographic;
(Phase II) LLM next-key behaviour is an open line, no corpus line exists; (Phase III) an open output code over a
periodic statistic yields only a small representational tilt and a transient behavioural bias in a from-scratch
transformer. A paper needs the natural twin-asymmetry-vs-frequency test above and a synthetic run in the data-sparse
regime (rare twins) to show the transient can be frozen in.

## 13. Single highest-information next experiment
Synthetic CIRCLE law with the **duplicated labels made rare** (sample the second spelling of each twin class with
probability 1–10% instead of 50%) under aligned vs permuted codes: does the twin-target asymmetry then fail to converge
within a natural-scale budget, producing a persistent behavioural line from a periodic statistic? If yes, the natural
line-of-fifths is plausibly an unfinished transient of enharmonic equalization under an open-line output code; if no,
the natural line must come from the statistics or from genuine tonal-spelling knowledge.
